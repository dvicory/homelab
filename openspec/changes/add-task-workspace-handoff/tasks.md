## 2. Hermes Vertical Slice

- [ ] 2.1 Add automatic broker-backed completion capture of `/workspace/output`, including a valid empty tree for prose-only tasks. Every model-facing Kanban artifact must be an explicitly selected normalized relative path naming a regular file under the trusted task workspace; broker-backed selections must additionally lie below `output/`. Kanban performs syntax-only validation before the broker call, rejecting absolute, traversal, URI, drive, host, empty-segment, or symlink-escape syntax without inspecting contents or filesystem nodes. Summary/result prose or fields must not discover paths. Native scratch/dir/worktree flows copy each selected relative file into native attachment storage before `done`.
- [ ] 2.2 Keep the required completion-finalizer failure-propagating. Kanban remains in its existing `running` state until a ready handoff exists; before `done`, the broker-backed finalizer must call `exports/prepare` for every selected artifact against that frozen handoff, and any prepare failure is a completion-operation failure. Native scratch/dir/worktree attachment-copy failure is likewise completion-critical. Broker `staging`/`publication_failed`/`quarantined` operation states must not become new Kanban task statuses. Same-ID replay after consume must not revalidate the active source; a fresh producer run gets a fresh finalization ID.
- [ ] 2.3 Validate broker-worker `artifacts` as explicit normalized relative paths naming regular files under the trusted task workspace and below `output/`; pre-capture validation is syntax-only, while broker `exports/prepare` validates each selected path as a regular file against the frozen handoff. - [ ] 2.4 Deliver human files only through export prepare/read/release from the frozen handoff. Subscriptions may carry recipients/channels but no files and may not infer output.
